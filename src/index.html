          Remove model?

          This removes the model from your library and deletes local cache files. Nothing on Hugging Face is deleted.

          Share the LLM API?

          Only the model inference API is exposed — not the control panel, chat, or llama web UI. Traffic uses a self-signed TLS certificate (clients will warn until they trust it). Callers need an API key. Default bind is Tailscale only. Restart the model after enabling.

          Share on Wi‑Fi / LAN too?

          Binds on all interfaces (0.0.0.0). Anyone on your LAN who has an API key can use the model. Prefer Tailscale only when you can.
