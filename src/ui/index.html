                  Remove model?

                  This removes the model from your library and deletes local cache files. Nothing on Hugging Face is deleted.

                  Let other devices connect?

                  Only the model API is shared — not Chat or Admin. Callers need HTTPS (self-signed cert warning is normal) and a key you create. Default is Tailscale-only. Restart the model after turning this on.

                  Share on Wi‑Fi / LAN too?

                  Binds on all interfaces (0.0.0.0). Anyone on your LAN who has an API key can use the model. Prefer Tailscale only when you can.

                  Remove linked LLM?

                  This removes the saved link from this PC only. The host is unchanged.

                  Add a model
